# 법률/약관 문서 안내

> 상태: **출시 전 검토용 초안**
>
> 이 문서 세트는 현재 저장소의 실제 MVP 흐름(매장 관리자 회원가입, 매장별 QR, 고객 이름·전화번호 수집, 2일 쿨타임, 게임 결과/쿠폰 저장, 90일 쿠폰, 직원 PIN 사용처리)을 기준으로 작성했다.
>
> 최종 배포 전 대한민국 변호사/개인정보보호 전문가의 검토를 권장한다. 특히 운영사업자 정보, 결제수단, 인프라 사업자, 국외이전 여부가 확정되면 반드시 다시 점검해야 한다.

## 1. 운영 주체 기본 구조

### A. 매장 관리자 데이터
서비스 운영사업자 `[운영사업자 상호]`가 개인정보처리자다.

대상 예시:
- 대표자 이름
- 대표 연락처
- 이메일
- 비밀번호 해시
- 매장 상호
- 사업자등록번호
- 매장 연락처/주소
- 결제 및 계약정보(유료화 시)

### B. 매장 고객 이벤트 데이터
권장 구조는 다음과 같다.

- 개인정보처리자(위탁자): **이벤트를 운영하는 각 매장**
- 개인정보처리 수탁자: **[운영사업자 상호]**

고객의 이름·전화번호·참여내역·게임 결과·쿠폰 정보는 해당 매장의 리뷰 이벤트 운영을 위해 처리하고, 운영사업자는 시스템 제공 및 유지보수 목적으로만 처리한다.

> 중요: 운영사업자가 고객 데이터를 매장 목적과 별개로 자체 광고, 교차매장 CRM, 제3자 판매, 개인단위 프로파일링에 사용하려면 현재 문서만으로는 부족하다. 그 경우 별도의 처리 근거, 동의, 고지 및 약관 개정이 필요하다.

## 4. 프론트엔드 필수 반영

### 매장 관리자 회원가입 `/admin/signup`
현재 회원가입 폼에는 약관 동의가 없으므로 출시 전 다음을 추가한다.

필수:
- `[필수] 서비스 이용약관 동의`
- `[필수] 개인정보 수집·이용 안내 확인/동의` (동의가 필요한 처리에 한함)

선택:
- `[선택] 마케팅 정보 수신 동의`
  - 이메일
  - SMS/카카오 등 채널을 분리 저장하는 것을 권장

선택동의를 거부해도 가입 및 서비스 이용을 막지 않는다.

### 고객 QR 참여 화면
고객 정보 입력 직전에 다음을 노출한다.

- 실제 매장명
- `[필수] 개인정보 수집·이용 동의`
- 개인정보처리자: 해당 매장
- 수탁자: `[운영사업자 상호]`
- 수집 목적/항목/보유기간/거부권 및 거부 시 이벤트 참여 불가 안내

고객용 마케팅 동의는 MVP에 넣지 않는다.

### 만 14세 미만
현재 서비스에는 법정대리인 동의 확인 기능이 없다. 따라서 MVP에서는:

> `만 14세 미만은 개인정보를 입력하여 이벤트에 참여할 수 없습니다.`

문구와 연령 확인 절차를 두는 것을 권장한다. 향후 14세 미만 참여를 허용하려면 법정대리인 동의 확인 기능과 별도 안내가 필요하다.

## 5. 개인정보 보유기간 권장값

### 고객 이벤트 개인정보
현재 기능을 기준으로 권장:

- 고객 식별정보(이름, 전화번호): **참여일로부터 120일**
  - 90일 쿠폰 유효기간 + 처리/분쟁 완충기간 30일
- 게임/쿠폰 통계: 식별정보 삭제 후 익명·집계화하여 보관 가능
- 보안 접속로그: **3개월** 권장

매장이 더 긴 고객 식별정보 보유기간을 원하면 별도 목적과 보유기간을 고객에게 고지해야 한다.

### 매장 관리자
- 회원/계약 종료 시까지
- 종료 후 30일 내 일반 계정정보 삭제
- 법령상 보존의무가 있는 거래기록은 해당 기간 동안 분리 보관

유료서비스 관련 법정 보존기간이 적용되는 경우 일반적으로:
- 표시·광고 기록: 6개월
- 계약/청약철회 기록: 5년
- 대금결제/서비스 공급 기록: 5년
- 소비자 불만/분쟁처리 기록: 3년

실제 거래가 사업자 간 거래인지, 소비자 거래에 해당하는지에 따라 적용관계는 달라질 수 있다.

## 6. 인프라/국외이전 확인

출시 인프라를 확정한 뒤 개인정보처리방침의 수탁자 및 국외이전 항목을 반드시 갱신한다.

확인 대상:
- AWS 사용 리전
- Cloudflare 프록시/Tunnel/CDN 사용 여부
- 결제대행사(PG)
- 이메일/SMS/카카오 알림톡 사업자
- 오류추적/분석 도구(Sentry, GA 등)

해외 사업자가 개인정보를 국외에서 보관·조회·처리하는 경우 개인정보 보호법상 국외이전 요건 및 고지사항을 별도 확인한다.

## 7. 리뷰 이벤트 운영 핵심 원칙

서비스와 매장은 다음을 요구하면 안 된다.

- 별점 5점 작성 조건
- 긍정적인 문구 작성 조건
- 부정적인 리뷰 삭제 조건
- 허위 방문/허위 리뷰 작성 유도

직원은 **리뷰 작성 여부 또는 적법한 방문 리뷰 참여 여부만 확인**한다.

상품 등 경제적 혜택을 받고 작성하는 리뷰에는 관련 법령 및 플랫폼 정책에 맞는 경제적 이해관계 표시가 필요할 수 있으므로 매장 운영 가이드에서 명확히 안내한다.

## 8. 변경관리

약관/처리방침 변경 시:

1. Git에서 버전과 시행일을 변경한다.
2. 중요한 변경은 시행 전 충분한 기간을 두고 관리자에게 공지한다.
3. 추가 동의가 필요한 개인정보 처리 변경은 기존 동의로 갈음하지 않는다.
4. 이전 버전을 별도 보관한다.

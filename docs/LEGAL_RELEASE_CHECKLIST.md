# Yut Review 법무·개인정보 출시 체크리스트

> 이 문서는 코드 분석 결과를 바탕으로 만든 **출시 전 검증 목록**이다.
> `legal/yut-terms-privacy-20260918` PR은 아래 Merge Blocker를 모두 해소하기 전까지 병합하지 않는다.

## 코드 기준으로 반영한 사항

- 이벤트 참여자 입력: 이름, 휴대전화번호, 개인정보 동의
- 고객 식별정보: 이름·전화번호 암호화, 전화번호 해시 및 끝 4자리
- 개인정보 정리: 참여일 기준 120일, 단 유효한 미사용 쿠폰이 있으면 종료 시까지 파기 유예
- 관리자 가입정보: 대표자명, 연락처, 이메일, 비밀번호, 매장명, 사업자등록번호
- 매장 관리: QR, 직원 PIN, 상품, 결과별 가중치·확률, 쿠폰
- 관리자 화면의 참여자 표시: 이름 + 전화번호 끝 4자리
- 통계 CSV: 고객 개인정보를 포함하지 않는 집계 데이터
- AI 기능: 고객 이름·전화번호가 아니라 비식별·집계 정보를 프롬프트로 사용하는 설계
- AI 공급자: 설정에 따라 OpenAI Responses API 사용 가능
- 현재 요금제: BASIC / STANDARD / PRO, 실제 PG 결제 연동은 별도 출시 준비 대상

현재 약관/처리방침은 **이벤트 운영 매장 = 이벤트 참여자 개인정보 처리주체, 소담랩스 = Yut Review 시스템 처리수탁자** 구조를 전제로 작성했다.

- [ ] 실제 매장 계약서에도 개인정보 처리위탁 조항을 포함
- [ ] 매장이 이벤트 목적 외로 참여자 정보를 이용하지 못하도록 계약에 명시
- [ ] 참여 매장별 고객 문의/삭제 요청 전달 프로세스 마련
- [ ] 회사 고객센터에서 삭제·열람 요청을 수신했을 때 매장과 처리하는 운영절차 마련
- [ ] 관리자 화면에서 전체 전화번호를 노출하지 않는 현재 정책 유지

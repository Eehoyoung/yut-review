# 구독 레벨별 기능 구현 현황

- 기준일: 2026-09-27
- 기준: 현재 작업 트리의 코드·테스트·설정
- 확정 가격: BASIC 9,900원 / STANDARD 14,900원 / PRO 19,900원 (월, 매장 1곳 기준)
- 상태 표기:
  - **구현**: 백엔드 권한과 실제 처리 경로가 존재하고 관리자 UI에서 접근 가능
  - **부분 구현**: 핵심 경로는 있으나 소개서 표현 전체를 충족하지 않거나 운영 의존성이 남음
  - **검증 필요**: 코드와 테스트는 있으나 이번 변경 후 백엔드 자동 테스트 또는 실제 운영 환경에서 확인하지 못함
  - **미구현**: 판매·운영에 필요한 실제 기능이 없음

> 이 문서는 코드 구현 현황이다. 로컬 코드에 존재하는 기능을 현재 운영 서버에 배포된 기능으로 간주하지 않는다.

## 2. 모든 요금제 공통 기능

구독 등급과 무관하게 아래 고객 경험은 동일하게 제공된다. 이 기능들은 `Entitlement`에 포함하지 않아 요금제로 잠글 수 없게 설계돼 있다.

| 기능 | 구현 상태 | 확인 내용 |
|---|---|---|
| 매장별 QR·비예측 토큰 | 구현 | 공개 고객 URL은 매장 토큰을 사용 |
| 상품·결과별 확률 설정 | 구현 | 서버가 설정 전체를 검증·저장하고 보안 난수로 결과 결정 |
| 3D 윷 게임 | 구현 | 서버 결과가 원본이며 프런트는 확정 결과를 연출 |
| 쿠폰 발급·조회·사용 | 구현 | 게임 생성과 발급이 한 트랜잭션이며 직원 PIN으로 사용 처리 |
| 2일 캘린더 쿨타임 | 구현 | `Asia/Seoul`, 매장+정규화 전화번호 기준 |
| 활성 쿠폰 우선 | 구현 | 미사용 쿠폰이 있으면 새 게임보다 기존 쿠폰 우선 |
| 직원 PIN | 구현 | 매장별 PIN, 다른 매장 쿠폰에 사용 불가 |
| 고객 개인정보 120일 정책 | 구현 | 구독별 분석 보관 기간과 분리 |

## 3. BASIC — 월 9,900원

| 포함 기능 | 상태 | 구현 근거와 남은 항목 |
|---|---|---|
| 공통 이벤트 운영 전체 | 구현 | QR, 게임, 상품, 쿠폰, PIN, 쿨타임은 플랜과 무관 |
| 기본 집계 | 구현 | 참여·쿠폰 발급·사용 중심 요약 API와 관리자 분석 화면 존재 |

## 8. 현재 검증 증거와 한계

### 확인된 것

- 프런트엔드 `npm run lint` 통과
- 프런트엔드 `npm run build` 통과
- 구독 작업지시 JSON 파싱 통과
- 기본·프로덕션 Docker Compose 구성 파싱 통과(예시 환경값 사용, 컨테이너 기동은 제외)
- 변경 파일 `git diff --check` 통과
- 코드·문서·랜딩의 가격이 9,900 / 14,900 / 19,900원으로 정렬됨
- 요금제별 권한 및 체험 회귀 테스트 코드가 현재 정책에 맞게 갱신됨

### 확인하지 못한 것

- 백엔드 전체 테스트: 현재 Windows 환경에서 Gradle이 `Unable to establish loopback connection`으로 시작 실패
- Docker 대체 테스트: Docker Desktop 엔진이 실행 중이지 않음
- 실제 OpenAI 호출과 비용·타임아웃·응답 품질
- 월요일 스케줄러의 운영 서버 실행 결과
- 실제 Safari, Android Chrome, Samsung Internet 및 인앱 브라우저 동작
- 프로덕션 배포 및 `hanpan.sodamlabs.kr`의 새 가격·권한 동작

## 9. 완료 판단

현재 상태를 “모든 구독 기능 완성”으로 판단하면 안 된다.

- **코드상 완료에 가까운 범위:** 공통 게임 기능, 기본/상세 분석, CSV, 플랜 권한, 쿼터, 무료체험 상태 전환
- **운영 검증이 필요한 범위:** 실제 OpenAI 호출, 주간 자동 생성, 백엔드 회귀 테스트, 프로덕션 배포
- **별도 제품 작업이 필요한 범위:** PG 결제, 자동 갱신, 환불·해지 자동화

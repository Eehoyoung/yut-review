# 소담한판 업종별 활용백과 구현계획

## 0. 목표

소담한판 홈페이지에 **업종을 선택하면 해당 업종에 맞는 운영예시 + 추천 경품 3~5개 + 추천 3단계 경품 구성 + 운영 팁**이 즉시 노출되는 "업종별 활용백과"를 구축한다.

핵심 목표는 다음 4가지다.

1. 소상공인 점주가 "우리 업종에서도 쓸 수 있나?"를 10초 안에 이해한다.
2. 영업 담당자가 업종별 링크를 바로 전달할 수 있다.
3. 업종이 늘어나도 코드 수정 없이 데이터 추가만으로 확장한다.
4. 장기적으로 업종별 SEO 랜딩페이지와 이벤트 자동추천 기능으로 확장한다.

---

## 1. 분류 전략

### 1-1. 기준축

업종 분류의 기준축은 소상공인시장진흥공단 상가(상권)정보의 상권업종분류를 사용한다.

- 대분류: 10개
- 중분류: 75개
- 소분류: 247개
- 구조: 대분류 → 중분류 → 소분류
- 코드: 대분류 2자리 / 중분류 4자리 / 소분류 6자리

이 분류를 DB의 `OFFICIAL` 계층으로 보관한다.

### 1-2. 영업용 세부 업종

공식 분류는 점주가 검색하는 표현과 다를 수 있으므로 별도의 `MARKETING_ALIAS` 계층을 둔다.

예:

- 공식: 한식 → 육류 요리
- 영업용 alias: 삼겹살집 / 돼지갈비 / 소고기집 / 곱창집 / 오리고기 / 닭갈비

- 공식: 비알코올 음료점
- 영업용 alias: 카페 / 개인카페 / 테이크아웃카페 / 디저트카페 / 브런치카페 / 베이커리카페

- 공식: 이용·미용 관련 서비스
- 영업용 alias: 미용실 / 남성전문미용실 / 바버샵 / 네일샵 / 속눈썹 / 왁싱 / 피부관리

즉, **공식분류는 누락 방지용**, **alias는 검색·영업·SEO용**으로 사용한다.

## 3. 세부 업종 페이지

경로 예시:

`/examples/food/korean/samgyeopsal`

페이지 구성은 모든 업종에서 동일하게 유지한다.

### 3-1. 헤더

- 업종명
- 한 줄 설명
- 추천 목적 태그

예:

> 삼겹살집에서 소담한판을 이렇게 활용해보세요
>
> 식사 마무리 순간에 작은 재미를 더하고, 다음 방문까지 연결하는 이벤트를 만들 수 있습니다.
>
> `재방문` `고객경험` `매장 이벤트`

### 3-2. 추천 운영예시

짧은 실전 시나리오 2~3개를 제공한다.

예:

#### 식사 후 참여형

계산 전 또는 식사를 마친 고객에게 QR 참여를 안내하고, 결과에 따라 즉시 경품 또는 재방문 혜택을 제공한다.

#### 테이블 이벤트형

테이블당 1회 참여 방식으로 운영해 직원 안내 부담과 경품 원가를 낮춘다.

#### 재방문 유도형

즉시 제공 경품보다 다음 방문에 사용할 수 있는 혜택 비중을 높여 재방문을 유도한다.

### 3-3. 추천 경품 후보 3~5개

업종별로 3~5개의 후보를 보여준다.

예: 삼겹살

- 음료 1병
- 계란찜
- 된장찌개
- 냉면
- 다음 방문 3,000원 할인

중요: **추천 경품 3~5개 = 후보군**이며, 실제 소담한판 운영에 적용하는 최종 경품 슬롯은 별도 추천 프리셋으로 제시한다.

### 3-4. 추천 3단계 운영안

서비스에서 실제 경품 단계가 3개라면 후보 3~5개 중 3개를 자동 선택해 프리셋을 만든다.

예:

- 기본 경품: 음료 1병
- 중간 경품: 계란찜
- 상위 경품: 다음 방문 3,000원 할인

프리셋 유형을 3종 제공한다.

#### 원가절약형

저원가 즉시보상 + 재방문 보상 중심

#### 균형형

즉시보상 2개 + 재방문보상 1개

#### 체감혜택형

고객 체감가치가 높은 혜택 위주

### 3-5. 운영 팁

업종별 2~4줄.

예:

- 테이블당 1회로 운영하면 원가 관리가 쉽다.
- 가장 높은 보상은 다음 방문 혜택으로 설정하면 실제 원가 부담을 낮추면서 체감가치를 높일 수 있다.
- 직원이 긴 설명을 하지 않아도 되도록 계산대·테이블에 QR 안내물을 배치한다.

### 3-6. 유의사항

업종별 규제 또는 플랫폼 정책상 확인이 필요한 경우에만 노출한다.

## 14. 규제·주의 업종 처리

### NORMAL

자동 추천 허용.

### CAUTION

운영예시는 노출하되 주의문구를 함께 노출.

### MANUAL_REVIEW

자동 경품추천 비활성.
관리자가 승인한 콘텐츠만 표시.

초기 수동 검토 대상으로 잡을 업종:

- 병·의원
- 약국
- 동물병원
- 변호사 등 일부 전문서비스
- 금융·보험 관련 업종
- 주류 중심 업종
- 기타 별도 법률·플랫폼 정책 검토가 필요한 업종

또한 리뷰 관련 이벤트 문구는 특정 별점·긍정 리뷰를 조건으로 보상을 주는 구조가 되지 않도록 별도 콘텐츠 가이드라인을 둔다.

10. 기존 프로젝트 디자인 시스템과 컴포넌트 스타일을 우선 사용한다.

## 결론

소담한판의 업종별 활용예시는 단순한 소개페이지가 아니라 아래 4개 기능을 동시에 수행하도록 만든다.

1. **영업도구** — "우리 업종에서도 된다"를 즉시 보여준다.
2. **온보딩도구** — 점주가 경품을 무엇으로 정할지 고민하는 시간을 줄인다.
3. **SEO 랜딩페이지** — 업종별 이벤트 관련 검색 유입을 확보한다.
4. **향후 추천엔진의 데이터 기반** — 업종·객단가·예산에 따른 자동 경품 추천으로 확장한다.

따라서 1차 목표는 "모든 업종 문구를 수작업으로 완성"하는 것이 아니라 **공식 업종분류 전체를 DB에 넣고, 영업성이 높은 50개 업종부터 고품질 콘텐츠를 완성하는 것**으로 잡는다.
